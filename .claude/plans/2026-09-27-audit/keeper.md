## 1. Cuts I oppose, or accept only in a modified form

**O-1 kernels-06 as originally written (WDTW: thread_local single-entry cache only) — OPPOSE; accept the verifier's form.**
`warping_wdtw.hpp:147-160`: `cached_w = wdtw_weights<data_t>(max_dev, g)` assigns a freshly returned vector on every miss, and the cache is keyed on one `max_dev`, so on variable-length data almost every pair along a row misses (heap allocation + O(max_len) `exp` calls inside the parallel fill). The f64 map path (`dtw_dispatch.cpp:176-185`) is an O(1) lookup with no allocation. For banded WDTW the DP is O(n·(2b+1)), so at b≈5-10 the rebuild is the same order as the DP. Do: per-length table built once at bind, held by value in the closure (serves f32 too); thread_local fallback that computes into its own buffer; one variable-length banded WDTW fill measured before/after. That removes the three mechanisms without the regression.
