Design (orchestrator; report any deviation with its reason before landing it):
1. `dtwc.cluster(data, k, Name, Value)`: CamelCase keys, the Config words (the CLI long names; `Band`, `MaxIter`, `Method`, `Device`, `WdtwG`, …). The MEX sets each given key on a `dtwc::Config` (one field-by-field list, as nanobind's Config binding is Python's), `apply`s it to a Problem holding the series and calls `Problem::cluster()`; defaults live only in C++ (a key not given is not sent). Method default `auto`. An unknown key is InvalidInput naming the valid keys. `cmd_tier1_cluster`'s positional transport and `cmd_cluster_legacy` go.
2. One `DTWClustering`, as W9b's Python one: fit = one Problem and NInit seeded runs with the matrix filled once; `predict`/score never refits; `MaxIter = 0` refused; its properties are the same CamelCase words. Problem.m regains read access to `Band`, `Verbose`, `MaxIter`, `NRepetitions` (PLAN W9e row).
3. Files, per Volkan 10-02 (the same file read the same way in every language): `dtwc.load` / `dtwc.Dataset` read CSV, TSV and folders of text files through the MEX-bound C++ text reader (one reader for C++, Python and MATLAB; no MATLAB re-implementation); result files (`Result.save`) through the MEX-bound C++ writer. Parquet and Arrow IPC: the MEX has no Arrow, so MATLAB reads them with its own `parquetread` (and `featherread` where it supports Arrow IPC / Feather V2 — check) and passes the series in memory; show on the tests/data/reader Parquet/Arrow files that MATLAB's series equal C++'s (or the same refusal); a format MATLAB cannot read is a clear `dtwc:invalidInput`, never a silent fallback. Already-read data: every entry takes a numeric matrix (one series per row) and a cell of vectors (ragged), as Python takes numpy arrays and lists; the docs page that shows loading shows this route next to load. Checkpoints and the matrix cache stay C++. The MEX's v1-style positional file entries that duplicate these go.
4. Function names stay the Python words (snake_case, as MATLAB's own toolbox functions are lowercase); only name-value keys and class properties are CamelCase.
Keep: conformance digit-identical in all three languages (MATLAB through matlab_suite); every bindings/matlab example runs; the CLI unchanged (25 runs, every output file, stdout without timing lines and the exit code byte-identical before and after, on data/dummy with --skip-rows 1 --skip-cols 1 -k 3: each method pam, clara, onebatch, tadpole, hierarchical, kmedoids, lrcore; pam --band 4300 and --band 10; pam --variant wdtw --wdtw-g 0.1, ddtw, adtw --band 4300; kmedoids --metric squared_euclidean --n-init 2; pam --missing-strategy zero_cost; tadpole --band 4300; --dtype float32 for clara, onebatch, pam and tadpole; hierarchical --linkage single; -k 1 for pam and kmedoids; -v for pam, pam -k 1 and onebatch); Python untouched except the contract-parity table rows that name MATLAB keys.
