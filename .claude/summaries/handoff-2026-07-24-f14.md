## Decisions

- The native format is ASCII full-matrix CSV, locale-independent general
  binary64 at `max_digits10`, comma-delimited, uncomputed NaN as empty, signed
  zero preserved, exactly one LF per row, no CR/BOM, and zero bytes for N=0.
- Computed positive or negative infinity is invalid input. Every route rejects
  in row-major order before the first matrix byte with the registered exact
  `InvalidInput` message.
- Stream insertion is independent of, and preserves, caller locale, flags,
  precision, fill, and width.
- F14 may share only scalar-token and finite-preflight primitives. It changes
  but does not consolidate or redirect the four row/delimiter/output loops;
  R4 retains that work.
- The permanent native-public gate always runs resident CLI and a C++
  `Result::save` helper and compares them. It additionally runs and proves mmap
  CLI when llfio is linked, while llfio-OFF reports capability unavailability
  without a test skip.
- One new tracked CMake integration script moves the registered manifest count
  from 26 to 27 in the F14 test commit.
- F37 owns the wider cross-language `Result::save`/CLI byte promise after F14.
- The implementation passed its registered band in attempt 1; attempt 2 was
  not used. Retain `e5bfd20`.
- F14 is closed. R4 still owns native formatter consolidation, and F37 still
  owns the confirmed Python plus runtime-unconfirmed MATLAB contradiction.
