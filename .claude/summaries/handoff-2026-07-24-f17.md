## Decisions

- `--resume` replays a completed or iteration-capped result exactly and skips
  clustering; it is not a warm start and does not add `--max-iter`.
- Missing, malformed, or structurally incompatible explicitly requested binary
  state fails loudly.
- Replay never rewrites the source binary checkpoint.
- F17 preserves binary v1 and documents that the caller must use the same input
  order and clustering configuration. Authenticated provenance remains outside
  this frozen-format repair.
- Streamed FastCLARA continuation remains R5/2.1 work.
