## Primary-source contract

Sakoe and Chiba impose monotonicity and continuity, fix the path endpoints at
`(1,1)` and `(I,J)`, and define the adjustment window by their equation (8):
`|i(k)-j(k)| <= r`. Their practical calculation domain repeats the same
constant-width condition as `j-r <= i <= j+r`. The paper is:

H. Sakoe and S. Chiba, “Dynamic Programming Algorithm Optimization for Spoken
Word Recognition,” *IEEE Transactions on Acoustics, Speech, and Signal
Processing*, 26(1), 43–49, 1978, DOI
[`10.1109/TASSP.1978.1163055`](https://doi.org/10.1109/TASSP.1978.1163055).
The accessed author/teaching-hosted scan is registered in
this run-log and `.claude/CITATIONS.md` is synchronized in the separate D1
derivation/documentation commit.

For zero-based implementation coordinates the adjustment window is therefore
`|i-j| <= band`. Because the required terminal cell is `(n-1,m-1)`, a nonempty
path requires `band >= |n-m|`. A window centred on the line joining the two
endpoints is a different, slanted constraint and is not used by this oracle.

## Preregistered mathematical oracle

The permanent test must implement a full-matrix oracle locally, independently
of the production row-bounds and rolling-buffer helpers:

```text
D(-1,-1) = 0
D(i,-1) = D(-1,j) = +infinity
D(i,j) = c(x_i,y_j) + min(D(i-1,j-1), D(i-1,j), D(i,j-1))
```

Only cells satisfying `|i-j| <= band` are evaluated. The mathematical
`+infinity` result is compared with DTWC++'s deliberate finite sentinel,
`numeric_limits<T>::max()`, because this build intentionally avoids an
infinity sentinel under its floating-point flags.

The non-degenerate discriminator is:

```text
x = [0, 1, 0, 2, 0]       n = 5 samples
y = [0, 0, 0, 0, 0, 0, 2] m = 7 samples
|n-m| = 2 samples
```

Amplitude has an arbitrary unit `U`; indices and `band` have units of samples.
Thus L1 accumulated cost has unit `U`, while squared-L2 accumulated cost has
unit `U^2`. No approximation or floating-point tolerance enters these
integer-valued fixtures.

The full-coverage count is the Delannoy count for paths from `(0,0)` to

all three rows before it can arbitrate the production/oracle disagreement.

## Preregistered non-metric witnesses

The D1 derivation distinguishes a non-negative symmetric dissimilarity from a
metric. The following deterministic witnesses are registered before adding or
executing their permanent assertions:

1. With L1 local cost, `x=[0,0]`, `y=[0,1]`, and `z=[0,1,2]` have
   `DTW(x,z)=3 U`, `DTW(x,y)=1 U`, and `DTW(y,z)=1 U`, so the triangle
   inequality is violated by exactly `1 U`.
2. With squared-L2 local cost, singleton series `x=[0]`, `y=[1]`, and `z=[2]`
   have `DTW(x,z)=4 U^2`, while `DTW(x,y)+DTW(y,z)=2 U^2`, so the triangle
   inequality is violated by exactly `2 U^2`.
3. For both local costs, distinct series `x=[0,1]` and `y=[0,0,1]` have
   distance exactly zero, falsifying identity of indiscernibles.

These integer-valued witnesses use no tolerance or approximation. Their
permanent test must drive the public `dtwFull` route and pin every operand, not
merely assert that some random violation may occur.
