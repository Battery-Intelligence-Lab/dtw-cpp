# W11b: the bindings follow `index_t`

Python returns labels and medoids as `np.int64` arrays; MATLAB returns them, `iterations` and a dendrogram's `n_points` as
doubles (1-based indices, exact to 2^53). Counts (`k`, `sample_size`, `batch_size`, `max_points`, the skip counts, the
`dist_by_ind` indices) are read as 64-bit in both; `max_iter`, `n_init`, `n_samples` and `band` stay `int`.
