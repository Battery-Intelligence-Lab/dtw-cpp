## What shipped

Two new metric elastic distances as DTW variants (the 2024 KAIS clustering
evaluation ranks MSM the single best clustering distance; DTW ≈ Euclidean for
k-medoids quality — so these are a QUALITY lever, not a speed one):

- `dtwc::core::msm_distance` (dtwc/core/msm.hpp) — Move-Split-Merge (Stefan,
  Athitsos & Das, IEEE TKDE 2013).
- `dtwc::core::twe_distance` (dtwc/core/twe.hpp) — Time Warp Edit (Marteau,
  IEEE TPAMI 2009), stiffness ν + edit penalty λ, front zero-padded series.

Standalone O(n·m) DP with a **rolling buffer over the shorter axis**
(O(min(n,m)) scratch) — both distances are metrics hence symmetric, so we
orient n_short ≤ n_long. Rolling buffer (not a full matrix) is required for the
long-series target: a full O(n·m) scratch would be ~512 MB/thread at n≈8k. The
`+∞` cells (TWE padding) use the `numeric_limits::max()` sentinel with guarded
addition — the build is -ffast-math and true infinities are not safe (same
convention as the DTW kernels).

Recurrences match **aeon 1.5.0** exactly (source read from
`aeon.distances.elastic._msm` / `._twe`): MSM `_cost_independent` +
`_independent_cost_matrix`; TWE `_twe_cost_matrix` with `_pad_arrs` (front zero
pad) and `_univariate_euclidean_distance` = |a−b| for univariate.

**Wiring (CasADi-style, all languages):** `DTWVariant::{MSM,TWE}` + params
`msm_c`, `twe_nu`, `twe_lambda` (dtw_options.hpp); dispatch `make_msm`/`make_twe`
(dtw_dispatch.cpp) + `dtw.cpp` runtime switch + `distance.hpp` facade
(`dtwc::distance::msm/twe`) + checkpoint enum↔string; CLI `--variant msm|twe`
with `--msm-c/--twe-nu/--twe-lambda` (+ TOML keys); Python `DTWVariant.MSM/TWE`,
`DTWVariantParams.{msm_c,twe_nu,twe_lambda}`, and the `KMedoids` wrapper.

**v1 scope (documented, not silent):** univariate + unbanded (window=None).
Multivariate is **rejected at bind time** (serial, before the parallel fill) with
a clear `InvalidInput`, never silently collapsed. `Problem::band` is intentionally
ignored (full O(n·m) elastic metric) — the default build is unbanded anyway.

## Registered bands (fixed BEFORE the runs) + verdicts

- **BAND-ORACLE [HARD] → CONFIRMED.** `msm_distance`/`twe_distance` == aeon
  1.5.0 to rel ≤ 1e-10 on 20 non-degenerate pairs (equal + unequal lengths)
  each. (Verified in isolation first: MSM 20/20, TWE 20/20.)
- **BAND-METRIC [HARD] → CONFIRMED.** Over 200 random triples ×2 distances:
  d ≥ 0; d(x,x)=0; symmetry d(x,y)==d(y,x) to 1e-12; triangle inequality
  d(x,z) ≤ d(x,y)+d(y,z)+1e-9 (both are true metrics — confirms the
  implementation preserves the metric property).
- **BAND-WIRING [HARD] → CONFIRMED.** A `Problem` with variant=MSM/TWE fills a
  distance matrix whose entries equal the direct kernel to 1e-10 (dispatch path
  correctness). CLI `--variant msm -k 3` runs end-to-end (converged, sensible
  labels) on the conformance dataset.
- **BAND-SPEED [ADVISORY, `[.]` bench, floor ≤1.3× plain DTW DP, warm timing]:**
  per-pair kernel wall-time vs `dtwFull_L` (plain DP, same structure):

  | len  | dtw(ms) | msm/dtw | twe/dtw |
  |------|---------|---------|---------|
  | 128  |  4.72   | 1.03×   | 1.30×   |
  | 256  | 18.99   | 1.03×   | 1.29×   |
  | 512  | 74.74   | 1.01×   | 1.26×   |
  | 1024 | 295.0   | 1.06×   | 1.30×   |

  **MSM → CONFIRMED comfortably (1.01–1.06×).** **TWE → CONFIRMED at the
  boundary (1.26–1.30×, marginal):** TWE's cell does strictly more work than DTW
  (front padding, two |·| terms + the 2ν|i−j| index penalty), so ~1.3× is the
  expected floor, not slack. Advisory / machine-dependent.
