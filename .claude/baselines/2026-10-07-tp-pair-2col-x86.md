## Method (all under `C:/D/git/wt/tmp/TP/`)

- **Core difference [confirmed].** `git diff --stat 418c28f2 0edc388b -- dtwc` lists only `dtwc/core/dtw_kernel.hpp`
  (+84/−22). `old/` and `new/` are `git archive` of `dtwc/core/` plus `dtwc/base/missing_utils.hpp` and `error.hpp` at
  each commit; `diff -rq old new` lists only `dtw_kernel.hpp`. The four headers the harness includes have no conditional
  on a project macro (only `__aarch64__`); HEAD `8a63cda3` has the same four as `0edc388b`.
- **Harness** (`bench.cpp`, from TB's). Timed entries `dtw_{l1,sq}_{f64,f32}`: each `run_dtw<SpanL1Cost |
  SpanSquaredL2Cost>(x, nx, y, ny, band, StandardCell{}, early_abandon)`, what `dtwBanded<T>` runs, `__declspec(noinline)`,
  called through a volatile pointer. Four fixed-seed pairs of i.i.d. uniform series per cell (exact random bits). Thread
  pinned to logical CPU 12 (a P-core) at `THREAD_PRIORITY_HIGHEST`; warm-up 0.4 × the target, then repetitions for
  ≈ 75 ms; every timed call compared bit for bit with the reference. Computed cells come from a call-counting functor
  around the library's cost, run through the same `run_dtw`; its result must equal the timed one (exit 3 otherwise).
- **Cells** (17, the table rows; `driver.py` `CELLS`). Early abandon at 0.5 × the pair's distance. Unbanded abandon: the
  two-column pass tests both columns' minima after the pass, so it computes one more column for 1 (n = 1000) and 2
  (n = 3000) of the 4 pairs; the ratio is per computed cell, so that +0.05 % / +0.03 % of cells is not charged to new.
- **Placements.** p0 as built; p1 the same source with `-DTP_PAD` / `/DTP_PAD`: `tp_pad` (8 `__nop()` and a ret, kept by
  `/include:tp_pad`, no caller) is the first function of `bench.cpp`, so everything after it moves 16 bytes. Per
  `placement.txt` (`placement.py`), every innermost FP-min loop of the timed entries starts at a different offset mod 64
  in p1 and holds the same code (clang old 56 loops, new 80; MSVC old 40, new 80).
- **Driver** (`driver.py`). `run`: 3 rounds; in each, both compilers, both placements, every cell, old then new (round 0,
  2) or new then old (round 1), one process per run, each line verbatim to `raw.txt`. `report`: per compiler a table
  with new/old per placement (median ns per computed cell; bold > 1.05), the verdict against the band, the unbanded
  speed-ups next to the M5's (k1 against base, p0 / p1 / p2 there, `phase2/summary.txt`), and `problems:` (every run exit
  0 and `ok=1`, each cell's result hash equal across all eight binaries, cells constant across runs, 3 runs per cell, no
  timed interval under 50 ms).
