# DTWC++ 2.1 milestone

Items intentionally outside the 2.0 release-candidate scope:

- TC-DTW lower-bound tightening for pruning/nearest-neighbour paths.
- A conda-forge feedstock in the external conda-forge organization.
- Oxford ARC end-to-end validation and production hardening of the HPC
  transport.
- MATLAB Tier-1 bindings for the post-freeze OneBatchPAM, LR-core, and TADPole
  additions; 2.0 keeps the original common method set and rejects these names
  loudly instead of substituting another algorithm.
- Runtime Metal verification on supported Apple hardware and reconsideration
  of Intel macOS wheels when a genuine x86_64 OpenMP runner is available.
- Cache/PMU profiling on a quiet privileged performance host before reopening
  a Highway/inter-pair SIMD prototype.
- A fresh quiet-host UCR spot benchmark immediately before final `v2.0.0`.

These are tracked as explicit follow-on work, not silent omissions from 2.0.
