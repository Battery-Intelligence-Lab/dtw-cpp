# DTWC++ 2.1 milestone

What 2.0 has not yet been shown to do; each item waits on another machine or on
the maintainers:

- **HPC submission.** `device("hpc")` and `"hpc:gpu"` in Python, and
  `slurm_remote.sh`, have not yet run end to end on Oxford ARC; treat them as
  beta until they have.
- **MATLAB on Windows.** The MATLAB test suite has not yet run against the
  Windows MEX under R2024b.
- **Release archives.** The Linux and Windows C++ archives have not yet been
  built and smoke-tested.
- **The same digits on every compiler.** The conformance run has not yet been
  compared under GCC and MSVC Release builds.
- **The Linux wheel.** Whether it ships the GNU OpenMP runtime, and its notice
  saying so, is still to settle.
- **CUDA with `auto` precision through a `Problem`** crashed once on Windows and
  has not been re-run.
