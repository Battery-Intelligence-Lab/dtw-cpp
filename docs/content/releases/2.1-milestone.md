# DTWC++ 2.1 milestone

What 2.0 has not yet been shown to do; each item waits on another machine or on
the maintainers:

- **HPC submission.** `device("hpc")` and `"hpc:gpu"` in Python, and
  `slurm_remote.sh`, have not yet run end to end on Oxford ARC; treat them as
  beta until they have.
- **MATLAB on Windows.** The MATLAB test suite has not yet run against the
  Windows MEX under R2024b.
- **Release archives.** The Windows C++ archive has not yet been built and
  smoke-tested. The Linux archive was built and smoke-tested on 2026-11-09
  (WSL).
- **The Linux wheel.** It is now built with clang and carries LLVM's OpenMP
  runtime, as the macOS and Windows wheels do. That chain ran natively on
  Ubuntu 24.04 x86_64 (WSL) on 2026-11-21; it has not yet run in the
  manylinux_2_28 containers, on x86_64 or aarch64.
